# Google ADK Labs 

A hands-on learning journey exploring Google's Agent Development Kit (ADK), Gemini, Vertex AI, and agentic AI systems.

This repository documents my experiments, practical implementations, and lessons learned while building AI agents with Google technologies.

My goal is to move beyond understanding AI agents theoretically and develop the engineering skills needed to design, build, evaluate, and deploy real-world AI agent systems.

##  Learning Objectives

- Understand the architecture of AI agents.
- Build agents using Google's Agent Development Kit (ADK).
- Integrate Gemini models.
- Explore Vertex AI and Google Cloud Agent Platform.
- Build agents with custom tools and external APIs.
- Implement sessions, memory, and context management.
- Develop multi-agent systems.
- Explore Retrieval-Augmented Generation (RAG).
- Evaluate, monitor, and deploy AI agents.

## Tech Stack

- **Language:** Python
- **Agent Framework:** Google ADK
- **AI Models:** Gemini
- **Cloud Platform:** Google Cloud
- **AI Platform:** Vertex AI

##  Getting Started

### Prerequisites

- Python 3.10 or later (check the compatibility requirements of your installed ADK release).
- Google ADK.
- Google Cloud account (for Vertex AI experiments).

### Clone the repository

```bash
git clone https://github.com/DidasMba/google-adk-labs.git

cd google-adk-labs
```

### Set up a virtual environment

```bash
python3 -m venv .venv

source .venv/bin/activate
```

### Install Google ADK

```bash
pip install google-adk
```

### Configure environment variables

Configure your credentials in the appropriate `.env` file for the experiment you want to run.

Never commit API keys, credentials, or other secrets to GitHub.

### Run the first agent

```bash
adk run agent_with_ADK
```
